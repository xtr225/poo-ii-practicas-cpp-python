El diseño A concentra tareas
Registro, promedio, archivos, correo y base de datos comparten clase. Un cambio de infraestructura puede afectar una clase que también representa reglas académicas.
El diseño B delimita responsabilidades
Estudiante maneja el dominio, el repositorio almacena y el exportador produce un formato de salida. Los esquemas todavía requieren interfaces y métodos completos.
Compilar o terminar sin errores no demuestra que una práctica esté completa. El C++ actual termina normalmente aunque acepte una nota fuera del rango pedido.
